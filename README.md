# 🧰 研发七部工具包

轴承数据分析与报告生成桌面工具集。

## 📦 功能模块

### 📊 边缘应力分析

对轴承 HTM 仿真数据进行解析、边缘尖峰去除、应力曲线绘制和报告生成。

- 📂 **数据导入** — 选择文件夹，递归扫描 HTM 文件，支持多次追加与去重；空状态卡片整块支持点击触发选择
- 🔍 **边缘尖峰去除** — 自动找出滚子两端的边缘尖峰，顺着应力弧线补平，每条曲线只留一个峰
- 📈 **报告生成** — 一键生成应力曲线 PNG（中/英文）、应力等高线图、载荷与应力雷达图、最大应力汇总 Excel
- ✏️ **交互式预览** — 独立窗口查看 Plotly 图表，支持拖拽编辑数据点实时更新报告
- 🖱️ **拖拽到 Word** — 预览窗口里的应力曲线、等高线图和雷达图可直接拖进 Word、PPT、Excel
- 🎯 **雷达图调整** — 在主页面参数面板或预览窗口均可调整载荷/应力雷达图的径向最小值

### 📊 Pmax 时间占比分析

对轴承最大接触应力（Pmax）按自定义区间分箱，计算各区间时间占比，生成柱状图。

- 📋 **数据输入** — 从 Excel 粘贴 4 列数据（持续时间 + Pmax 前/后轴承）
- 🔧 **分箱参数** — 前/后轴承分别设置最小值、最大值、步长
- 🎨 **图表样式** — 自定义字号（标题/标签/刻度/标注）和图形尺寸
- 🌐 **中英文切换** — 图表标题和坐标轴标签支持中/英文
- 📈 **柱状图生成** — 前/后轴承分别生成时间占比柱状图，显示在右侧「图表预览」里
- 🖱️ **拖拽到 Word** — 图表预览中的图片可直接拖进 Word、PPT、Excel

### 📉 载荷简化

把风电齿轮箱各工况的时序载荷按各分量的区间分组，缩减成少量等效工况，输出 Romax 直接能用的载荷表。

- 📂 **文件格式** — 选载荷文件夹（连同子文件夹里的 txt）后自动读第一个文件的开头，认出要跳过的行（列名、END_OF_HEADER）和每一列是时间、转速还是哪个力 / 力矩；在「文件格式」弹窗里核对列对应，用不到的列选「不使用」
- 🔢 **单位换算** — 力、力矩读进来后除以力转换系数、力矩转换系数，转速乘以转速转换系数，换成 KN、KNm、rpm；默认 1000、1000、1，对应文件里是 N、N·m、rpm，同样在「文件格式」弹窗里改
- 📥 **加载数据** — 读全部 txt 和频次表，统计六个分量的最值和加权时间占比分布
- ✂️ **区间划分** — 区间表的下界、上界自动填数据的最值，中间最多填 9 个分段点；分布图和网页版一样，点右上角的「X 轴区间选择」后横向拖选几根柱，看它们的时间占比合计
- 🧮 **载荷缩减** — 按区间分组缩减，写出 GL 和 Romax 两个 Excel；改了区间、坐标映射或缩减参数，直接再缩减，不用重新加载
- 💾 **保存配置** — 登录后点标题栏右侧的「保存配置」，把现在的路径、文件格式、单位换算、缩减参数和区间表存到 TMB 服务器上，和网页版的「存储」存在一起；项目名取输出目录的文件夹名，自己存过同名的会被覆盖
- 🕘 **历史记录** — 登录后点标题栏右侧的「历史记录」，按项目名查自己存的配置（网页版存的也在），点一条就把路径、文件格式、单位换算、缩减参数和区间表填回来

### 👤 账号

- 🔐 **登录** — 侧栏左下角「登录」，用网页版的工号和密码。登录不是必需的：连不上内网时工具照常用，只有查、存载荷简化的历史记录要登录
- ⚠️ **一处登录** — 同一账号只能在一处登录，这里登录后网页版上的这个账号会退出登录
- 🔄 **保持登录** — 连着内网打开应用会自动续期，超过 7 天没续上才要重新登录；登录状态存在本机的 account.json，不存密码；点左下角的名字可以退出登录

### 📜 日志

- 🧾 **运行记录** — 侧栏左下角的「日志」显示这次打开应用以来的记录：每个请求和它的结果、后端的提示和报错，以及界面上的报错；出错时写明原因，带报错详情的行点开能看
- 🔍 **筛选与搜索** — 按级别只看警告或错误，或者搜关键字；停在最底下时新的记录会自动滚出来；「清屏」只清掉页面上已有的
- 📋 **反馈问题** — 「复制」把当前筛出来的记录复制下来发给开发者；「打开日志目录」里每次打开应用单独一个文件，文件名是启动时间（如 backend-20261015-103152.log），最近 7 天的都在，重开过几次也找得回

### ⚙️ 设置

- 🌗 **外观切换** — 浅色 / 深色 / 跟随系统三种模式
- 🌐 **语言** — 预留中文/英文切换（即将推出）
- 💾 **持久化** — 设置数据通过 Tauri Store 插件保存在本地 JSON 文件（settings.json），重启后自动恢复

## 🚀 使用步骤

### 📊 边缘应力分析

1. 启动应用，在侧边栏点击「边缘应力」进入分析页面
2. 点击左侧的「选择文件夹」（或直接点击右侧的空白区域）导入包含 HTM 文件的目录
3. 在左侧参数栏设置「输出目录」「图片尺寸」「雷达图最小值」（0 表示自动）
4. 点击左下角的「开始解析」，右侧文件列表上方显示进度（按钮下方会提示当前缺什么前置条件）；每个文件处理完，这一行就显示列数，悬停文件名可看缩略图，被跳过的文件在文件名下面写明原因（太长时悬停看全文）
5. 全部解析完成后，点击眼睛图标弹出独立预览窗口
6. 在预览窗口中可切换列号、滚道；点「拖拽编辑」后拖动数据点，松手后报告图片自动重画；报告图片可直接拖进 Word、PPT、Excel
7. 生成的报告文件保存在输出目录的 `res-output/` 子目录中

> 安装或更新后第一次打开应用时，后台的解析服务要几十秒才能就绪：这时点「开始解析」会先停在「正在连接解析服务…」，就绪后自动开始。之后每次打开只要一两秒。

### 📉 载荷简化

1. 在侧边栏点击「载荷简化」
2. 左侧「数据」区选「载荷文件夹」「频次表」和「输出目录」。频次表只认列的顺序，依次是文件名、全寿命发生次数、仿真时间（s），文件名要和 txt 一一对应；txt 里有时间列时，仿真时间按时间列算
3. 「文件格式」区显示力、力矩、转速三个转换系数，以及自动认出的跳过行数和列数。不对就点它右上角的「设置」：上面改单位换算，力、力矩除以各自的转换系数（文件里是 N、N·m 时填 1000），转速乘以转速转换系数（文件里是 rad/s 时填 9.5493）；下面对着第一个 txt 的开头几行（跳过的行灰掉）核对每一列对应的分量，用不到的列选「不使用」
4. 点「加载数据」，按钮下方会提示还缺什么
5. 加载完右侧显示区间表和分布图：下界、上界已填好数据的最值，在中间从小到大填分段点，留空的格子不切；点一行，下面的分布图切到这个分量，点图右上角的「X 轴区间选择」后横向拖选几根柱，看占比合计
6. Romax 坐标、扭矩分量、转换系数（S-N 曲线斜率）、温度、占比阈值在「缩减参数」右上角的「设置」里改；点左下角「载荷缩减」
7. 改了区间、缩减参数或输出目录可以直接再点「载荷缩减」；改了载荷文件夹、频次表或文件格式，要先重新加载
8. 加载的数据一直占着内存，用完点数据区右上角的「清空」释放，参数和区间表会留着

> 配置调好了想留着下次用：点标题栏右侧的「保存配置」（没登录时先登录），确认框里写着要存成的项目名，就是输出目录的文件夹名；自己存过同名的，会被这次存的整条覆盖，想留着旧的就换个输出目录。
>
> 想接着用存过的配置（网页版存的也在）：点标题栏右侧的「历史记录」，按项目名搜索，点一条，路径、文件格式、单位换算、缩减参数和区间表都会填好，核对后从第 4 步加载数据。载荷文件夹在这台电脑上不存在时，「文件格式」区会提示读不到，改成本机的路径即可。

### 📜 遇到问题时

1. 点侧栏左下角的「日志」，在上面选「错误」，看最近的报错和原因；带详情的行点开能看到报错的位置
2. 想重新试一遍、只看这一次的记录：先点「清屏」，再去做刚才出错的操作，回来看新出来的几行
3. 要反馈给开发者：点「复制」，把复制的记录贴过去；或者点「打开日志目录」，把出问题那次的日志文件发过去：每次打开应用单独一个文件，文件名是那次的启动时间（如 backend-20261015-103152.log），最近 7 天的都在

## 📁 输出文件说明

### 📊 边缘应力分析

解析完成后，在输出目录下生成以下文件：

```
res-output/
├── 最大应力汇总.xlsx                                # 所有文件所有列的最大应力值
└── {组名}/
    ├── {文件名}-内滚道接触应力-第{N}列-中.png       # 内圈应力曲线（中文）
    ├── {文件名}-内滚道接触应力-第{N}列-英.png       # 内圈应力曲线（英文）
    ├── {文件名}-内滚道接触应力-第{N}列-contour.png  # 内圈应力等高线图
    ├── {文件名}-外滚道接触应力-第{N}列-中.png       # 外圈应力曲线（中文）
    ├── {文件名}-外滚道接触应力-第{N}列-英.png       # 外圈应力曲线（英文）
    ├── {文件名}-外滚道接触应力-第{N}列-contour.png  # 外圈应力等高线图
    ├── {文件名}-第{N}列-载荷雷达图.png              # 载荷分布雷达图
    └── {文件名}-第{N}列-应力雷达图.png              # 应力分布雷达图
```

### 📉 载荷简化

缩减完成后，在输出目录下生成以下文件，文件名带输出目录的名字：

```
Load_Reduction_GL-{目录名}.xlsx      # 按各分量的区间标签分组的工况：时间、转速、各分量载荷
Load_Reduction_Romax-{目录名}.xlsx   # Romax 格式：工况表格定义、载荷矩阵及其转置，力和力矩按 Romax 坐标换算
```

## 🔧 技术栈

- **前端** — Tauri v2 (Rust) + Vue 3 + TypeScript + Naive UI
- **后端** — Python (FastAPI)
- **构建** — Tauri + Vite + Nuitka

## 💻 开发

```bash
# 后端（先启动，前端依赖其 :8006 接口）
cd backend
uv sync          # 安装依赖
uv run main.py   # 启动 FastAPI 服务 (端口 8006)

# 前端
cd frontend
cnpm install         # 安装依赖
npm run tauri:dev    # 启动 Tauri 应用（自动起渲染层 Vite :5179）
```
