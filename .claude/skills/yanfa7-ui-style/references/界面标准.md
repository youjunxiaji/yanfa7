# 界面标准

整体设计语言是 Apple / macOS 风格的浅色 bento 卡片。工具页的骨架样式在 `src/renderer/src/assets/main.css` 的
「工具页通用样式」段（卡片外壳、卡片头、参数表单与 bento 分区、底部行动条、输入框），暗色覆盖在同一文件
「暗色模式」开头、按页面分小节的那一大段。页面只写差异，骨架复用全局类。

基准页：工具页 `EdgeStressView.vue`、`PmaxView.vue`；阅读型页面 `SettingsView.vue`（也是现有唯一用 CSS 变量的页面）。

## 一、工具页骨架

```text
.<name>-page             // height:100%; display:flex; flex-direction:column
└── el-row.page-row      // :gutter="20"; flex:1; min-height:0; align-items:stretch
    ├── el-col :span="10"    // 输入 / 参数区
    │   └── el-card.page-card (shadow="never")
    │       ├── #header → .card-header（左 图标 + 标题，右可选 tag / 按钮）
    │       ├── .config-form（flex:1 撑满，内含多个 .config-section）
    │       └── .action-bar（底部行动条，主按钮）
    └── el-col :span="14"    // 内容 / 结果区（文件列表、图表、预览）
        └── el-card.page-card …
```

- 输入 / 参数区占 10，内容 / 结果区占 14；左右顺序按页面主流程排：边缘应力先选文件，「数据文件」（14）在左、
  「参数配置」（10）在右；Pmax 先配参数，「参数配置」（10）在左、「图表预览」（14）在右。
- `:deep(.el-col){display:flex;flex-direction:column}` 让左右卡片等高撑满。
- `.config-section`（bento 子卡）`flex:1` 均分高度、`#f8f8fa` 底、`:focus-within` 蓝光圈，靠 flex 撑满面板，
  不出内部滚动条。输入项多时收紧 `gap`（现用 8px：Pmax 输入项最多，要这个值才能在约 700px 高的窗口里放下），不加滚动。
- 卡片体三段：头部 → `.config-form`（撑满）→ `.action-bar`。

| 角色 | 亮色 | 暗色（`html.dark`） |
|---|---|---|
| 品牌蓝 | `#0071e3`（渐变终点 `#2997ff`） | `#0a84ff` |
| 成功 / 绿 | `#34c759` | `#30d158` |
| 危险 / 红 | `#ff3b30` | `#ff453a` |
| 文本 主 / 次 / 三 | `#1d1d1f` / `#86868b` / `#424245` | `#f5f5f7` / `#a1a1a6` / `#636366` |
| 页面背景 | `#f5f5f7` | `#1c1c1e` |
| 卡片背景 | `#ffffff` | `#2c2c2e` |
| bento 分区底 | `#f8f8fa` | `#1f1f21` |
| 边框 | `#ececef` / `#e5e5ea` | `#38383a` / `#48484a` |

- 新代码的品牌蓝一律写 `#0071e3`。Element Plus 的运行时主色没有覆盖，仍是默认的 `#409eff`，所以 `type="primary"`
  的组件现在显示的是 `#409eff`（统一主色记在 `todo.md`）；手写样式里不再出现 `#409eff`。
- 主行动按钮用蓝渐变 `linear-gradient(135deg, #0071e3, #2997ff)`。
- 次级文本灰统一 `#86868b`，不引入 `#909399`、`#6e6e73` 这类 Element Plus 风格的灰。
- 颜色目前是各处硬编码的 hex，没有全局设计变量；新代码尽量复用 `main.css` 已有的类，少写新 hex。

## 三、间距 / 圆角 / 阴影 / 边框

- **圆角**：小元素（输入框、小按钮、列表项）`8px`；bento 分区、列表容器 `10px`；主按钮、空状态、进度块 `12px`；
  大卡（`.page-card`）、模态 `14px`；胶囊、进度条 `999px`。
- **阴影**：卡片双层柔阴影 `0 1px 2px rgba(0,0,0,.04), 0 4px 12px rgba(0,0,0,.04)`；浮层（命令面板、模态）
  `0 16px 48px rgba(0,0,0,.16), 0 0 0 1px rgba(0,0,0,.06)`；主按钮品牌阴影 `0 1px 3px rgba(0,113,227,.25)`，hover 抬升。
- **间距**：卡片头 `14px 18px`、卡片体 `16px 18px`；分区 gap `8px`、表单行 gap `10px`；模块之间 `margin-top: 14px`；
  `.action-bar` 顶部用 `1px dashed #ececef` 分隔。
- **边框**：卡片实线 `1px solid #ececef`，输入框、图片 `#e5e5ea`；空状态虚线 `2px dashed #e4e4e7`。

## 四、字号 / 字重

- 字体栈 `-apple-system, BlinkMacSystemFont, 'Segoe UI', 'PingFang SC', 'Microsoft YaHei', sans-serif`；
  路径、代码用等宽 `'SF Mono', 'Menlo', 'Monaco', monospace`。
- **字号**：正文、标签 `13px`（主力）；辅助小字 `12px`；按钮、空状态标题 `14px`；卡片标题、设置项 `15px`；
  `.section-label` `11px`；页面级大标题 `22px` / `28px`。
- **字重**：`700` 重标题和 `.section-label`；`600` 卡片标题、强调；`500` 按钮、标签；`400` 正文描述。
- **细节**：统计、百分比这类数字列加 `font-variant-numeric: tabular-nums`；`.section-label` 用 `text-transform: uppercase`
  + `letter-spacing: .6px`；大标题用负字距 `-0.5px`。

## 五、Element Plus 用法

- **按钮**：主操作 `type="primary"`；危险 `type="danger" plain`；次级 `plain`；列表行内 `text size="small"`。
  页面主行动按钮用自定义渐变类（`size="large"`、高 44、圆角 12），不可用时加 `--inactive` 态（`opacity: .55` + 去阴影），
  不直接用灰色禁用样式。
- **表单**：不用 `el-form-item`，用自定义 `.form-row`（label 定宽 + 控件横排）。`el-input-number` 一律
  `controls-position="right"`（圆角、聚焦蓝圈已在 `main.css` 全局重写）；浏览类按钮放 `el-input` 的 `#append` 插槽。
- **对话框**：`el-dialog` 三种用途——信息反馈（`width≈560`、`align-center`）、数据录入（`:close-on-click-modal="false"`
  + `@opened` 自动聚焦）、图片放大（`width="80%"` 或 `fullscreen`）。含 iframe 或 Plotly 的对话框加 `destroy-on-close`。
- **反馈**：行内瞬时提示用 `ElMessage.{success,warning,error}`；带标题的通知用 `ElNotification`。`duration` 普通 `3000`、错误 `5000`。
- **其他**：二次确认 `el-popconfirm`；`el-tooltip` 用 `:show-after="400"`；状态和计数用 `el-tag`（`round size="small"`）；
  分段切换 `el-segmented`。

## 六、可复用交互模式

- **可点击空状态**：`.empty-state` 虚线卡，整块 `@click` 触发主操作，hover 时边框转品牌蓝、图标上移。
  现在各页各写了一份，抽到通用段之前照现有写法。
- **进度三态**：`.progress-block` 的 `--processing` / `--done` / `--error`（蓝 / 绿 / 红），处理中图标加 `spin` 动画，
  配 `el-progress :show-text="false" :stroke-width="8"`。
- **缺前置提示**：主按钮 `:disabled` + `--inactive`，下方淡入一行 `.parse-hint`（带 `InfoFilled`）说明为什么不能点
  （如「请先选择数据文件」），不静默禁用。
- **本地图片**：`convertFileSrc(path)` 加 `?t=` 时间戳，图片重画后更新时间戳（见 Tauri Skill 的本地文件一节）。
- **拖拽导出**：`<img draggable="true" @dragstart>` 里 `preventDefault()` 后调 `window.electronAPI.startDrag(path)`。
- **命令面板**：`⌘P` / `Ctrl+P` 全局唤起（`App.vue` 监听，`CommandPalette.vue`）。
- **悬停预览**：文件名上 `el-popover trigger="hover" placement="right"` 显示结果缩略图。

## 七、图标 / 资源

- 图标全用 `@element-plus/icons-vue`：`<el-icon :size="N"><IconName /></el-icon>`，常用 `14`（label 内）、`16`（行内）、
  `18`（卡片头）、`28~64`（空状态、加载）。按名字动态取的图标用 `markRaw` 注册进 `iconMap`。
- 状态图标固定：`CircleCheckFilled` 成功、`WarningFilled` 警告、`InfoFilled` 信息、`Loading` 加载。
- 静态资源放 `assets/`；本地文件一律经 `convertFileSrc` 显示。

## 八、尺寸与布局

- 不用媒体查询。最小窗口 **1100×700**，布局靠 flex + `el-row` / `el-col :span` + `min-height: 0` 自适应；
  高度紧张时收紧 `gap` 撑满，不加滚动条。
- 阅读型页面居中定宽：首页 `520px`、设置 `560px`、文档 `800px`；Pmax 的图表图片最宽 `720px`。

## 九、暗色样式

- 主题怎么切换（`setTheme` + `<html>` 的 `.dark` class、跟随系统）见 Tauri Skill；这里只管样式。
- Element Plus 组件靠 `main.ts` 引入的 `element-plus/theme-chalk/dark/css-vars.css` 自动适配。
- 自定义样式的暗色覆盖统一写在 `main.css`，用 `html.dark .xxx` 选择器，按页面分小节；不写进组件的 `<style scoped>`。
- 新组件里有硬编码颜色就补对应的 `html.dark` 覆盖，色值取第二节的暗色列。
- 工具页共用的暗色规则（`.page-card`、`.config-section`、`.empty-state` 等）在「边缘应力页」小节，Pmax 页复用，
  只补自己专有的类（`.bin-col-title`、`.bin-label`、`.chart-label`、`.stats-section`、`.paste-*` 等）。

## 检查清单

- 工具页套了骨架和全局类，没有另写卡片外壳；输入区 10、结果区 14。
- 没有新的 `#409eff`、`#909399`；新写的 hex 都在 `main.css` 补了 `html.dark` 覆盖。
- 空数据、处理中、完成、出错几种状态都有界面；主按钮不可用时有 `--inactive` 和原因提示。
- 长文件名、长路径不撑破布局（截断或 tooltip）。
- 窗口缩到 1100×700 时不出滚动条、不溢出。
- 含 iframe 或 Plotly 的 `el-dialog` 有 `destroy-on-close`。
