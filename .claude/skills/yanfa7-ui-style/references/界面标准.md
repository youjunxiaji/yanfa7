# 界面标准

整体是中性、紧凑的桌面工具风：浅灰窗口底、白色内容面板、1px 细线分隔，全局只有一个品牌蓝（强调色）。
使用者在 Windows 上用，按 1280×800 设计；macOS 只是开发环境，不追 Mac 原生的样子。

## 一、外壳

```text
窗口（系统标题栏，不自绘）
└── .app（flex 行，底色 --canvas）
    ├── aside.sidebar          展开 216 / 收起 56，内边距 10 8 8
    │   ├── .brand             TMB Logo（高 13）+ 竖分隔线 + 「研发七部工具包」13/600，点击回首页；收起时只留 Logo
    │   ├── 首页
    │   ├── 分组标题「工具」    12，--text-3；收起时换成一条细分隔线
    │   ├── 各工具页
    │   ├── 弹性空白
    │   ├── 文档、设置
    │   ├── .nav-account       TMB 账号入口，上边一条 --divider（见下）
    │   └── .sidebar-footer    左边版本号（12，--text-3），右边折叠按钮
    └── main.main              内边距 8 8 8 0（左边贴侧栏）
        └── .panel             撑满；1px --border、圆角 10、--shadow-sm、overflow hidden，页面自己管滚动
```

- 侧栏不放搜索框，菜单项少，直接点就行；跳转快捷键是命令面板（见第八节）。
- 账号入口长得同导航项：没登录是 `CircleUserRound` +「登录」，点开登录弹窗；登录后是 20 的圆形头像
  （中文名首字 12/600，`--accent` 字、`--accent-soft` 底）+ 中文名，点开 `n-popover`（`placement="right-end"`、
  不显示箭头）：32 头像、姓名 600、工号 · 部门（12，--text-3），下面是「退出登录」，悬停变 `--danger`。
- 导航项 `.nav-item`：高 32、圆角 7、左右内边距 9，图标 16 + 文字 13/500，项间距 2。
  默认文字 `--text-2`、图标 `--text-3`；悬停底色 `--hover`；选中底色 `--nav-active`，外加 1px `--nav-active-ring` 环和
  `--shadow-sm`，图标变 `--accent`。收起时只显示图标，悬停出 `n-tooltip`（`placement="right"`）。
- 导航数据只有一份：`router/index.ts` 的路由 `meta` 里放 `title`、`icon`（`@lucide/vue` 图标组件，`markRaw`），
  工具页再加 `tool`（完整名称、一句话说明、色调）；侧栏、命令面板、首页工具卡和页面标题栏都从这里读，不各写一份。

## 二、尺寸

- 1280×800 是设计基准。这时内容面板约 1056×784；工具页参数栏 340，结果区约 714 宽，结果区工具栏下面约 686 高。
  这个尺寸下参数栏一屏放下，结果（列表、图表）完整可见或可以滚动看到。
- 最小窗口 1100×700：结果区约 534 宽。允许结果区滚动、参数栏自己滚动、页面说明截断；不允许横向滚动和元素重叠。
- 侧栏收起后内容区多 160 宽，布局不依赖侧栏状态。
- 不写媒体查询，靠 flex / grid 加 `min-width: 0`、`min-height: 0` 适配。需要滚动的只有结果区和参数栏，
  页面和面板本身不滚。

## 三、工具页骨架

```text
.page（flex 列，撑满面板）
├── header.page-header        高 52，左右内边距 20，下边 1px --divider
│   ├── .page-icon            28×28、圆角 7，品牌色浅底 + 16 图标（每个工具一个色调，见第四节）
│   ├── .page-title           15/600
│   ├── .page-desc            一句话说明，12.5，--text-3，放不下截断
│   └── .page-actions         可选，靠右：页面级的次要操作，`n-button size="small"`（如载荷简化的「保存配置」「历史记录」）
└── .tool-body（flex 行）
    ├── section.param-pane    宽 340 固定，右边 1px --divider
    │   ├── .param-scroll     参数分区，放不下时只有这里滚动
    │   │   └── .param-section × n    内边距 16 20，分区之间 1px --divider，区内间距 10
    │   │       ├── .section-head     分区标题 13/600；右侧放次要操作（清空）或单位说明（12，--text-3）
    │   │       ├── .field × n        标签列 84 + 控件列，标签 --text-2
    │   │       └── .section-note     补充说明，12，--text-3
    │   └── .param-footer     内边距 14 20 16，上边 1px --divider；主按钮 + 缺前置提示
    └── section.result-pane   撑满剩余宽度
        ├── .result-toolbar   高 44：结果标题 13/600 + 数量胶囊 .count-pill + 右侧提示或操作
        ├── StatusStrip       可选：处理中 / 完成 / 失败条带（第八节）
        └── .result-body      列表、图表或空状态，内容多了在这里滚动
```

- 顺序固定：参数栏在左，结果区在右。参数栏从上到下按操作顺序排：数据来源（选文件夹、粘贴数据）→ 输出位置 → 参数；
  结果区的空状态里再给一次数据来源的入口。
- 一页只有一个主按钮（`type="primary" size="large" block`），钉在 `.param-footer`；其他按钮用默认样式或文字按钮。
- 分区高度由内容决定，不拉伸、不均分；参数栏剩下的空白留在底部。
- 参数排法：
  - 一个值一行用 `.field`。
  - 两个相关的值放一行：宽 × 高中间放 `×`（12，--text-3）；载荷 / 应力这类用输入框的 `#prefix` 标签区分。
  - 多组同类参数用网格，比如 Pmax 分箱：标签列 52 + 前轴承 + 后轴承两列，第一行是列标题（12，--text-3）。
  - 关键说明写在控件下面（`.field-hint`，如「0 表示自动」），不藏进 tooltip。
- 文件列表、结果表用 `n-data-table`，撑满 `.result-body`（外层 `position: relative`，表格 `position: absolute; inset: 0`，
  开 `flex-height`）。
- 图表结果在 `.result-body` 里纵向滚动，内边距 16 20；每张图完整显示，不裁切；宽度够时并排（单图最小 440 宽），
  一张图的高度不超过结果区可见高度。
- 骨架类写在 `assets/main.css`；标题栏用 `components/PageHeader.vue`，图标、名称、说明取自路由 meta。
  页面只写差异，不另写外壳。

## 四、设计变量

颜色、阴影和字体全部是 CSS 变量，数值在 `src/renderer/src/assets/tokens.css`：`:root` 是浅色，`html.dark` 是暗色。
Naive UI 的 `themeOverrides` 在 `src/renderer/src/theme/naive.ts`，用同一套字面值，改一边必须同步另一边。

| 变量 | 用途 |
|---|---|
| `--canvas` | 窗口底、侧栏底 |
| `--panel` | 内容面板、窗格、弹窗 |
| `--subtle` | 次级底：统计条、代码块、弹窗操作区 |
| `--muted` | 计数胶囊、空状态图标底、分段控件轨道 |
| `--hover` / `--pressed` | 悬停 / 按下底色 |
| `--border` | 面板、输入框、图片边框 |
| `--border-strong` | 悬停边框、空状态虚线 |
| `--divider` | 面板内分隔线、表格行线 |
| `--text-1` | 标题、正文、输入值 |
| `--text-2` | 标签、次要正文 |
| `--text-3` | 说明、占位、表头、未选中图标 |
| `--accent` / `--accent-hover` | 品牌蓝：主按钮、选中、焦点、进度 |
| `--accent-soft` | 品牌蓝浅底：处理中条带、页面图标底、空状态悬停、首页版本号胶囊 |
| `--success` / `--success-soft` | 完成 |
| `--warning` / `--warning-soft` | 跳过、提醒 |
| `--danger` / `--danger-soft` | 失败、删除 |
| `--nav-active` / `--nav-active-ring` | 侧栏选中项底色 / 描边 |
| `--paper` | matplotlib 图片底，暗色下也是白 |
| `--mask` | 弹窗、命令面板遮罩 |
| `--shadow-sm` | 内容面板、侧栏选中项 |
| `--shadow-md` | 悬停浮起的卡片、图片 |
| `--shadow-lg` | 弹窗、命令面板 |
| `--font-sans` / `--font-mono` | 界面字体 / 路径和代码 |

- 只有一个强调色。TMB 品牌红只出现在 Logo 里，界面里的红色只表示失败和删除。
- 工具的色调只用在页面图标和首页工具卡上：边缘应力用品牌蓝（`--accent` / `--accent-soft`），
  Pmax 用绿（`--success` / `--success-soft`），载荷简化用琥珀（`--warning` / `--warning-soft`）；
  新工具从这几组里选，不新加颜色。

## 五、字体与字号

- 字体用 `--font-sans`：Inter 管英文和数字（`@fontsource-variable/inter`，`main.ts`、`preview.ts` 各引一次，
  按 unicode-range 只加载用到的子集），后面接 Segoe UI 和系统中文字体。路径、代码用 `--font-mono`。
- 字号：

| 字号 | 用在 |
|---|---|
| 12 | 辅助说明、表头、胶囊、提示、分组标题 |
| 12.5 | 页面说明、空状态说明 |
| 13 | 正文、标签、控件、表格（主力） |
| 14 | 空状态标题、阅读页正文 |
| 15 | 页面标题、弹窗标题 |
| 22 / 26 | 设置页标题 / 首页标题 |

- 不用 12 以下的字号。中文不加字距，不用 `text-transform`；大标题可以用 `-0.02em` 负字距。
- 字重：400 正文；500 导航项、按钮、表头、设置项名；600 页面标题、分区标题、强调数值；700 阅读页大标题。
- 行高 1.55；阅读页正文 14 / 1.75。数字列、进度、统计值加 `font-variant-numeric: tabular-nums`。

## 六、间距、圆角、边框

- 间距按 4 的倍数取：面板离窗口边 8；分区内边距 16 20；分区内元素间距 10；控件之间 6~8；结果区内边距 16 20。
- 圆角：

| 圆角 | 用在 |
|---|---|
| 4 | 小标签、`kbd` |
| 6 | 按钮、输入框、分段控件、图标按钮 |
| 7 | 导航项、页面图标 |
| 8 | 图片框、统计条 |
| 10 | 内容面板、图卡、预览窗格 |
| 12 | 空状态、弹窗、首页工具卡 |
| 999 | 胶囊 |

- 分隔用 1px `--divider`；要成块的地方用 1px `--border` 包边，不用灰底色块层层叠。
- 阴影只用第四节的三档；按钮、输入框、分区都不加阴影。

## 七、Naive UI

- `components/AppProviders.vue` 是主窗口（`App.vue`）和预览窗口（`preview.ts`）共用的根：`n-config-provider`
  的 `theme` 取 `isDark ? darkTheme : null`，`locale` / `date-locale` 用 `zhCN` / `dateZhCN`，里面再包 `n-message-provider`；
  图标默认线宽也在这里用 `setLucideProps` 设。
- 入口 HTML 的 `<head>` 最前面有 `<meta name="naive-ui-style" />`，Naive 的样式插在它前面，项目样式在后面，
  同等优先级时项目样式生效。
- 主题覆盖的要点（数值在 `theme/naive.ts`）：
  - `common`：主色 = `--accent`；控件高 28 / 32 / 36（small / medium / large）；圆角 6；字号 13；字体同第五节。
    控件和表格的文字（Naive 的 `textColor2`）比 `--text-2` 深一档：浅色 `#27272a`、暗色 `#e4e4e7`。
  - 默认按钮、输入框、下拉框悬停只把边框加深到 `--border-strong`，不变蓝；聚焦时边框变 `--accent`，外加 3px 浅蓝光圈。
  - 实色按钮（primary 等）文字一律白色；Naive 暗色主题默认是黑字，要覆盖。
  - 表格：表头底色和面板相同，表头文字 `--text-3`、500；行线 `--divider`；small 尺寸单元格内边距 7 12。
  - 分段控件（`n-tabs` 的 segment）：轨道 `--muted`，选中块浅色白、暗色 `rgba(255,255,255,.12)`，选中文字 500。
  - tooltip 用深底白字（浅色 `#18181b`、暗色 `#2a2a2e`）；`n-split` 的拖拽条默认透明，悬停才显示浅蓝。
- 组件选用：

| 用途 | 组件与写法 |
|---|---|
| 主按钮 | `n-button type="primary" size="large" block`，参数栏底部，一页一个 |
| 普通按钮 | `n-button`（默认样式），图标放 `#icon` 插槽 |
| 文字操作（清空等） | 原生 `button.link-btn`：12、`--text-3`，危险操作悬停变 `--danger`；配 `n-popconfirm` |
| 行内图标按钮 | 原生 `button.icon-btn`：26×26、圆角 6，悬停 `--hover` 底；配 `n-tooltip` |
| 路径输入 + 浏览 | `n-input-group`：`n-input`（`clearable`、`#prefix` 放文件夹图标、`title` 显示全路径）+ `n-button` |
| 数值 | `components/NumberInput.vue`：包了 `n-input-number`，不显示 +/- 按钮（键盘 ↑↓ 调值），`suffix` 写单位（如 `in`）、`prefix` 区分并列的值；清空时不回写，字段始终是数字 |
| 两到四个选项；按数据生成、个数不多的选项（如列号，有几项就几段） | `n-tabs type="segment" size="small"` + `n-tab` |
| 下拉选择 | `n-select size="small"` |
| 表格 | `n-data-table size="small" :bordered="false"`，单元格内容用列的 `render` |
| 弹窗 | `n-modal preset="card"`，宽 560~680，按钮放 `#footer` 右对齐；录入类加 `:mask-closable="false"`，在 `@after-enter` 里聚焦 |
| 二次确认 | `n-popconfirm`，不显示图标（`:show-icon="false"`），按钮文字写动作（「清空」「取消」） |
| 提示 | `n-tooltip`，`delay` 200~300 |
| 可能很长的文字（报错原因等） | `n-ellipsis`：一行放不下截断，截断了才悬停出全文；tooltip 加 `contentClass: 'long-tip'`（`main.css`，限宽 360 折行） |
| 悬停预览 | `n-popover trigger="hover" placement="right"`，不显示箭头 |
| 进度 | `n-progress type="line" :height="4" :show-indicator="false" processing` |
| 可拖分栏 | `n-split` |
| 瞬时反馈 | `useMessage()`，组件外用 `createDiscreteApi(['message'])`；顶部居中，成功 3 秒、失败 5 秒 |

- `n-data-table` 的单元格由 `render` 函数生成，不带组件的 scoped 标记，单元格样式要写在 `:deep()` 里
  （见 `EdgeStressView.vue`）。`n-ellipsis` 的根节点同样不带，给它的样式也写在 `:deep()` 里（见 `StatusStrip.vue`）。
- 侧栏导航不用 `n-menu`，用第一节的 `.nav-item`。
- 页面外壳不用 `n-card`，用第三节的骨架类；`n-card` 只以 `n-modal preset="card"` 的形式出现。

## 八、交互模式

空状态和进度条带做成 `components/EmptyState.vue`、`components/StatusStrip.vue`，各工具页共用。

- **空状态** `EmptyState`：结果区里的虚线框（1.5px `--border-strong`、圆角 12、外边距 20），中间是 44×44 图标块（`--muted` 底、
  圆角 12、图标 20）+ 标题（14/600）+ 一句说明（12.5，--text-3）+ 一个按钮。整块可点，悬停时边框变 `--accent`、
  底色 `--accent-soft`、图标块变白底蓝图标。
- **忙碌态**：同一个虚线框换成转圈图标 + 「正在扫描文件夹…」这类文字，边框保持 `--accent`，鼠标显示 `progress`。
- **进度条带** `StatusStrip`：结果区工具栏下面一条，内边距 10 20：
  - 处理中：`--accent-soft` 底，转圈图标 + 「正在处理 <文件名>」+ 右侧 `i / n · 百分比`，下面一条 4px 进度条；
  - 完成：`--success-soft` 底，`circle-check` + 生成文件数，有跳过的写上跳过数；
  - 失败：`--danger-soft` 底，`triangle-alert` + 失败原因。
  - 文字一行放不下就截断，悬停看全文（`n-ellipsis`）。
- **文件状态列**：文件表第一列只放图标，悬停给文字说明：

| 状态 | 图标 | 颜色 |
|---|---|---|
| 未解析 | `file-text` | `--text-3` |
| 排队 | `clock` | `--text-3` |
| 处理中 | `loader-circle`（转圈） | `--accent` |
| 完成 | `circle-check` | `--success` |
| 跳过 | `circle-alert`，原因写在文件名下面一行（12，`--warning`），放不下截断、悬停看全文 | `--warning` |
| 失败 | `circle-x` | `--danger` |

- **缺前置提示**：主按钮 `disabled`，下面一行 `info` 图标 + 原因（「请先选择数据文件」），居中、12、`--text-3`；
  不只是灰掉。
- **悬停缩略图**：解析完成后，文件名上挂 `n-popover`，显示各列的结果图（每张宽 200）。
- **本地图片**：`convertFileSrc(path)` 拼 `?t=` 时间戳，重画成功后更新（见 Tauri Skill）。图片放进 `--paper` 白底、
  1px `--border`、圆角 8 的框里；能放大的图悬停时边框加深、加 `--shadow-md`，鼠标 `zoom-in`，点开用 `n-modal`。
- **拖拽导出**：图片 `draggable="true"`，`@dragstart` 里 `preventDefault()` 后调 `window.electronAPI.startDrag(path)`；
  图卡标题栏右侧写「拖到 Word」。
- **命令面板**：⌘P / Ctrl+P 全局唤起（首页的快捷键胶囊也能打开），宽 540、距顶 16vh；列出全部页面，每项都有图标；
  ↑↓ 选择、Enter 打开、Esc 关闭，底部一行写这三个键。
- **报告预览窗口**（独立窗口）：
  - 顶部工具栏高 48：文件名 + 列号（segment，有几列就几段）+ 内外滚道（segment），两个分段控件每段一样宽。
  - 下面 `n-split` 分三栏：交互图表 / 应力曲线 / 雷达图，每栏是带 42 高标题栏的圆角窗格，窗格之间留 10。
  - 「拖拽编辑」是交互图表窗格标题栏上的开关按钮，开启后按钮变 primary 浅色、图表上方出一条说明。
  - 雷达图最小值的输入框放在雷达图窗格的标题栏里。
  - 应力曲线、等高线图、雷达图和放大弹窗里的图都能拖出去（上面的拖拽导出），图片标题行和弹窗标题栏右侧写「拖到 Word」。

## 九、图表

- matplotlib 出的 PNG 不跟主题变色，统一放第八节的白底框里。
- Plotly 图跟随主题：`paper_bgcolor`、`plot_bgcolor` 透明；网格线 `--divider`，坐标轴线 `--border-strong`，
  刻度文字 `--text-3`，坐标轴标题 `--text-2`，字体同界面；颜色序列用 Plotly 默认。
  变量值用 `getComputedStyle(document.documentElement)` 读出来传给 Plotly，切换主题后重画
  （`ReportPreviewView.vue` 的 `renderPlots`）。
- 带 Plotly 的组件卸载时调 `Plotly.purge`。
- 例外：载荷简化的分布图（`SimpleLoadHistogram.vue`）照搬网页版的 ECharts 配置，工具栏、框选都不改，使用者习惯了。
