# yanfa7 UI 风格

本 Skill 管外观与交互；模块行为查 `yanfa7-ref`，主题切换、拖拽、本地图片等原生能力查 `yanfa7-tauri`。
细则见[界面标准](references/界面标准.md)。

界面正在从 Element Plus 迁到 Naive UI，步骤见 `todo.md`。现有页面还是 Element Plus 和 `main.css` 里的旧全局类：
旧页面上的小改动沿用该页现有写法；新页面和整页重做按本 Skill，不照着旧页面的组件和样式写。

## 共用选择规则

- 风格是中性、紧凑的桌面工具：浅灰窗口底、白色内容面板、1px 细线分隔，全局只有一个品牌蓝；
  不用渐变按钮、大阴影，参数分区不撑满高度。
- 窗口按 1280×800 设计（应用默认尺寸）；缩到最小 1100×700 时不能横向溢出或重叠，结果区可以滚动。
- 外壳是左侧栏 + 右侧一整块圆角内容面板；侧栏只放导航，不放搜索框，页面跳转用 ⌘P / Ctrl+P 命令面板。
- 工具页（设参数 → 出结果）套界面标准第三节的骨架：左边 340 宽的参数栏，右边结果区；一页一个主按钮，在参数栏底部。
- 阅读型页面（首页、设置、文档）居中定宽，不套工具页骨架。
- 颜色、阴影只用设计变量，组件里不写 hex，也不写暗色覆盖。
- 组件只用 Naive UI，图标只用 `lucide-vue-next`。
- 优先复用界面标准第八节的交互模式（空状态、进度条带、文件状态列、缺前置提示等），不重造。

## 实现与验证

1. 先读界面标准里对应的章节，在要改的页面里改，保留业务逻辑、校验和异常处理。
2. 要新颜色时先在 `assets/tokens.css` 加变量，亮、暗两个值都给，再在组件里引用。
3. 按界面标准末尾的检查清单逐项核对代码：空数据、处理中、完成、出错、禁用、长文件名和长路径、
   1280×800 与 1100×700 两种窗口、亮暗两种主题。
