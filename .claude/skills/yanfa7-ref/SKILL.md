# yanfa7 工具模块参考

## 工作方式

1. 从索引选当前任务的模块，先读参考，再按其中的「关键文件路径」核对源码；跨模块时补读关联参考。
2. 涉及界面外观用 `yanfa7-ui-style`；选文件、预览窗口、拖拽、本地图片等原生能力用 `yanfa7-tauri`；打包发版用 `yanfa7-release`。
3. 新增工具模块时读[新增工具模块](references/新增工具模块.md)，登记前后端，并在下面的索引补一行。

## 参考维护

- 保留模块背景、数据流、行为契约、影响正确性的非显然原因和「关键文件路径」。
- 字段、默认值、样式数值和内部算法指向源码；接口摘要保留定位与用途，不逐项转录请求模型。
- 外观规范链接 UI Skill，原生能力链接 Tauri Skill；不在各模块重复。
- 本次改动影响参考内容时同步。
