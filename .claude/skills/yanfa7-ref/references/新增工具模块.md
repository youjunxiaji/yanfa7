# 新增工具模块

仅在加一个新工具（新页面 + 后端接口）时读取。代码组织和命名沿用项目规则，界面按 UI Skill。

## 后端

1. 建 `backend/app_<模块名>/`：`urls.py`（`router = APIRouter()` 注册路由）、`views.py`、`serializers.py`
   （Pydantic 请求 / 响应模型）、`module/`（解析、计算、出图）。
2. 在 `backend/main.py` 里 `app.include_router(...)`。
3. 接口挂 `/api/<模块名>/...`，WebSocket 挂 `/ws/<模块名>/...`，和 Pmax 的 `/api/pmax/analyze` 一样带模块前缀；
   边缘应力的接口没有模块前缀，是存量写法，不照抄。
4. 和前端共用的枚举放 `backend/common/constants.py`，前端在 `src/renderer/src/constants/` 放取值一致的一份。
5. 出图类模块：PNG 写到用户选的输出目录，或系统临时目录下自己的子目录（如 Pmax 的 `yanfa7_pmax`），
   把绝对路径返回给前端，由前端用 `convertFileSrc` 显示。

## 前端

1. `src/renderer/src/api/<模块名>.ts`：从 `@renderer/api/backend` 取 `API_BASE` / `WS_BASE`，封装请求和类型；
   后端返回 400 时读 `detail` 抛错（参考 `api/pmax.ts`）。
2. `src/renderer/src/views/<Name>View.vue`：按 UI Skill 的工具页骨架写，标题栏用 `PageHeader`。只属于本页的状态
   留在组件里；要跨组件共享时建 `stores/<模块名>.ts`（Options API）。
3. 登记导航只改 `router/index.ts`：加路由，`meta` 写 `title`（侧栏和命令面板里的短名）、`icon`（`@lucide/vue` 的图标组件，
   `markRaw` 包一层）和 `tool`（`name` 完整名称、`desc` 一句话说明、`tone` 取 `constants/ui.ts` 的 `ToolTone`）。
   侧栏「工具」分组、命令面板、首页工具卡和页面标题栏都从这里读；文档、设置这类放侧栏底部的页面写 `bottomNav: true`，
   不写 `tool`。
4. 需要选文件、拖拽、开窗口这类原生能力时走兼容垫片，见 Tauri Skill。
