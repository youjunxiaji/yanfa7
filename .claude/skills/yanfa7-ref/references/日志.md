# 日志

## 业务背景

侧栏底部「日志」页（文档和设置之间）显示这次运行的后端日志和界面报错，出了问题直接在应用里看原因，
或者复制、把日志文件发给开发者。页面只看这次运行：后端重启后从头开始；之前几次运行的去日志目录找，按启动时间命名、留 7 天。

## 数据流

```text
后端 loguru ──┬─ stderr ──→ 开发：跑 uv run main.py 的终端；打包：外壳写进这次运行的日志文件
              └─ LogBuffer（内存里最近 2000 条）←─ GET /api/logs?session=&after= ── stores/logs.ts（日志页开着时每秒一次）
标准库 logging（uvicorn、httpx）── StdlibInterceptHandler ──→ loguru
界面 logError / logWarning、没接住的报错 ── POST /api/logs ──→ loguru（来源「界面」）
```

## 行为约定

- 内存里只留 INFO 及以上的最近 2000 条。每条带这次运行里递增的 `seq`，前端带上次取到的 `seq` 只取新的；
  `session` 每次启动换一个，前端带的对不上（开发时热重载、打包后重开应用）就从头给，页面清掉旧的。
- 多行的日志第一行当内容，其余几行和报错堆栈进详情；`logger.exception` 的堆栈也在详情里。
  后端写日志时第一行写清是什么事，要堆栈就用 `logger.exception`。
- 来源三种：后端代码和第三方库写的是「后端」；访问记录和请求出错的原因是「请求」；渲染层报上来的是「界面」。
- 访问记录改写成「方法 路径 状态码」，4xx 记警告、5xx 记错误；WebSocket 握手记「WebSocket 路径 已连接」，
  websockets 库每次连上、断开打的 connection open / closed 不记；日志页自己轮询的 `/api/logs` 不记，不然每秒一条。
- 请求出错的原因记在访问记录前一条：422（请求和模型对不上，前端发错了）记错误，写明哪个字段，不记填的值（登录请求里有密码）；
  400（业务错误）记警告，写下 `detail`；401 和 502 不另记。载荷简化的 `send_error` 和边缘应力推 error 时也把同一句话记成「请求」的警告。
- uvicorn 用 `log_config=None` 起，不装自己的 handler，输出全走 loguru。开发时热重载的子进程会把 main.py 执行两遍
  （multiprocessing 的 `__mp_main__` 和 uvicorn 导入的 `main`）：`LogBuffer.install` 只装一次 sink，uvicorn logger 的
  handler 每次都摘，两遍之间 uvicorn 配过一次日志。
- 界面：`api/logs.ts` 的 `logError` / `logWarning` 照常打到控制台，同时报给后端；后端没就绪或连不上时攒着（最多 100 条），
  下一次报的时候补上。主窗口和预览窗口都挂了 Vue 的 `errorHandler`、window 的 `error` 和 `unhandledrejection`。
  渲染层不直接写 `console.error`。
- 页面：级别分段是「至少到这一级」，搜索匹配来源、内容和详情；停在最底下时跟着新日志滚动；「清屏」只记下当时最后一条的
  `seq`，之前的不显示，后端和日志文件里还在。数据放在 store 里，切到别的页面再回来还在，只在页面开着时轮询。
- 日志文件（只有安装版）：外壳每次启动新建一个，按启动时间命名（`backend-20261015-103152.log`，同一秒再开一个加 `-2`），
  先删掉 7 天前的；一个文件写到 10 MB 就不再写，防止报错死循环把硬盘写满。「打开日志目录」经 command
  `backend_log_path` 拿到这次运行的文件，在资源管理器里选中它；开发版不拉起后端、没有日志文件，按钮不可用。

## 关键文件路径

```text
backend/app_log/module/buffer.py                   # LogBuffer（内存、sink、安装）、StdlibInterceptHandler
backend/app_log/views.py                           # GET / POST /api/logs，422 和 400 的记录
backend/main.py                                    # LogBuffer.install()、两个异常处理器、uvicorn log_config=None
frontend/src/renderer/src/api/logs.ts              # fetchLogs、logError / logWarning、installErrorReporting
frontend/src/renderer/src/stores/logs.ts           # 轮询、去重、清屏
frontend/src/renderer/src/views/LogView.vue
frontend/src/renderer/src/shims/tauri-bridge.ts    # openLogDir
frontend/src-tauri/src/backend.rs                  # 每次运行一个日志文件、留 7 天、10 MB 上限
```
